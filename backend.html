Featured Project

ClearPort: Customs Clearing & Forwarding SaaS

A mobile-first, multi-tenant SaaS for Nigerian clearing & forwarding agents and customs-bonded terminals. It runs the whole import-clearance lifecycle, from Form M to empty container return, on a double-entry accounting core, and field staff can keep working offline at the port

Live App
Installable PWA → FastAPI → PostgreSQL

React 19 PWA with offline outbox → nginx (TLS) → Docker Compose: nginx web · FastAPI API · PostgreSQL 16, deployed from GitHub Actions via GHCR

Offline Sync, Exactly Once

  • Stage updates and photos queue in one ordered outbox (IndexedDB)
  • Every write carries an Idempotency-Key, so retries never double-post
  • 4xx responses are dropped; network errors, 5xx and 401 keep the queue in order
  • Updates stay tied to the user who made them on shared phones

Workflows as Data

  • Port Import (20 stages) and Bonded Import (25 stages)
  • Each stage declares its required documents, fields and permission
  • Overrides and reverts need their own permission and are audited
  • Demurrage, terminal storage and Form M expiry countdowns

Double-Entry Accounting

  • Every business event maps to an explicit debit/credit posting
  • VAT 7.5% on fees only, WHT credits, immutable journals and reversals
  • Two-person refund approval and accounting period lock
  • 7 financial reports, including job profitability and AR aging

Multi-Tenancy & Access

  • Every tenant-owned row scoped by organization; other tenants get 404
  • 45+ permission codes grouped into 12 editable roles
  • Own / branch / org data scope applied in the query layer
  • Audit log records who, when, and from which IP or GPS location

Featured Project

Fleet & Finance Platform (Odoo 19)

Custom ERP modules for a haulage company that turn truck dispatches, fuel purchases, driver cash advances, workshop maintenance and spare-part control into correct accounting, with profit tracked per truck

Operations → General Ledger

Dispatch · Sales · Vendor Bills · Stock Valuation → journal items tagged per truck → Truck Ledger P&L, Fuel Vendor Statements, MD-approved spare parts

Fleet Dispatch & Payables

  • Trip state machine: Draft → Dispatched → Returned → Done
  • Vendor bill for fuel and cash advance posted in the same transaction
  • Locked-period cancellations issue credit-note reversals
  • Parent-company fuel vendor statements with running balances

Per-Truck Profit & Loss

  • Reads posted journal items, so it always reconciles with the P&L
  • Truck required on transport sales orders and invoices
  • Workshop parts charged to trucks via perpetual stock valuation
  • SQL backfill brought historical trips into the ledger

Spare Parts Approval

  • High-value parts held until the Managing Director approves
  • Shows time and km since the last replacement, from store or vendor
  • Server-side enforcement, self-approval prevention, auto re-approval
  • Chose this design after weighing five options

Release Engineering

  • One-command deploy refuses uncommitted or unpushed code
  • Backs up every database before upgrading
  • Checks installed module versions before restarting
  • Docker Compose with Docker secrets; separate training database
