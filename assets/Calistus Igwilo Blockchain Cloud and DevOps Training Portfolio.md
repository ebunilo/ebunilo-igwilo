# **NITDA Blockchain Scholarship Programme**

I anchored and coordinated the programme for over 45,000 students, delivering technical training and learner support covering Bitcoin theory, hash functions, enterprise blockchain, JavaScript and Go. I appointed state coordinators and coordinated active learner communities across all 36 states of Nigeria, connecting national delivery with local engagement and support.

The programme archive includes technical lessons, seven walk-in sessions, onboarding, programme guidance and a session with the BSV team. Its 27 recordings have approximately 381,000 cumulative YouTube views as of October 2026\.

# **Cloud and DevOps programme**

I delivered 11 tutorials comprising more than 21 hours of recorded instruction for Cloud/DevOps students. Topics span networking and IP subnetting, AWS website hosting, system administration, file management, cloud network design, high availability and Git/GitHub collaboration.

# **Skills demonstrated**

Technical instruction and mentoring; AWS infrastructure and networking; blockchain and programming foundations; architecture communication; version control and collaborative development; live facilitation; programme coordination; delegation and nationwide community leadership.
