AWS → Contabo Migration (LOUD Social & Payments Platform)

Senior Cloud Architect / DevOps Engineer · Loud Products Limited · Aug – Oct 2026

Recommended and led the migration of a 16-microservice Spring Boot platform off AWS, from the options analysis through to production.

  • Audited the code and live AWS account; found the "managed" databases were self-hosted on one EC2 box in the wrong region
  • Designed a 5-node hybrid active-active topology behind a Cloudflare load balancer, with a private-only data tier
  • Codified every server in 13 idempotent Ansible roles with 6 Vault-encrypted secret stores
  • Migrated ~58,500 MySQL and MongoDB records and 5.1 GB of media (S3 → MinIO), every count verified
  • Built a GitHub Actions → Ansible pipeline with mandatory dry runs and rolling deploys
  • Fixed 16 pre-launch defects, including live payments routed to a sandbox and leaked cloud keys
  • Built Prometheus, Grafana and Loki observability with external uptime and TLS probes

Results: Infrastructure cost cut by 95% (~$5,000 → ~$250 a month), zero records lost, 3 public ports per server. Read the full case study.

ERP Release Pipeline (Odoo 19 Fleet & Finance Platform)

Solution Architect & Sole Engineer

Built a safe, one-command release process for custom Odoo modules running in production for a haulage company.

  • Ran Odoo and PostgreSQL on Docker Compose, with the database password as a Docker secret
  • Kept custom code in its own private repo, pulled with a read-only deploy key
  • Refused to deploy uncommitted or unpushed code
  • Backed up every database before each release, keeping the last 10
  • Checked logs, registry load and module versions against manifests
  • Restarted only when every check passed, and printed the restore point on failure
  • Kept a separate training database and wrote down the restore procedure

Results: Replaced hand-copied production changes with automated deployments that back up first and check their own result. Production always matches a commit on GitHub.
