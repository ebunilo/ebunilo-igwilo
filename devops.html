ERP Release Pipeline (Odoo 19 Fleet & Finance Platform)

Solution Architect & Sole Engineer

Built a safe, one-command release process for custom Odoo modules running in production for a haulage company.

  • Ran Odoo and PostgreSQL on Docker Compose, with the database password as a Docker secret
  • Kept custom code in its own private repo, pulled with a read-only deploy key
  • Refused to deploy uncommitted or unpushed code
  • Backed up every database before each release, keeping the last 10
  • Checked logs, registry load and module versions against manifests
  • Restarted only when every check passed, and printed the restore point on failure
  • Kept a separate training database and wrote down the restore procedure

Results: Replaced hand-copied production changes with automated deployments that back up first and check their own result. Production always matches a commit on GitHub.
